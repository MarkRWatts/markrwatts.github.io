# markrwatts.github.io

Personal brand site for Mark Watts &mdash; cybersecurity executive CV, career history and content hub.

Static HTML/CSS/JS, deployed via GitHub Pages from the `main` branch.

## Structure

- `index.html` &mdash; home page
- `about.html` &mdash; profile, philosophy, skills, certifications
- `experience.html` &mdash; full career history
- `insights.html` &mdash; speaking engagements and future writing
- `css/styles.css` &mdash; shared stylesheet
- `js/main.js` &mdash; nav behaviour
- `assets/` &mdash; favicon and images

## Local preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```
